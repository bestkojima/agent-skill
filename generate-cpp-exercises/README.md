# C++ 知识点实践出题

告诉 AI 你正在学什么知识点，一起确定练习方向，再生成一道用 C++ 实现的小 demo 练习题。

## 让 AI 安装

解压后，将整个 `generate-cpp-exercises` 文件夹放到 AI 能访问的位置。把下面的路径替换成实际路径，然后将这段话发送给 AI：

```text
请将 /实际路径/generate-cpp-exercises 安装为当前用户可用的 skill。
请根据当前工具确认正确的安装位置，完整保留 SKILL.md、references 和 agents 等文件。
安装完成后检查文件是否完整、技能是否已被识别，并告诉我如何调用。
如果需要重新加载或重启，请说明。
```

如果只想在当前项目使用，把第一句改成“请将 /实际路径/generate-cpp-exercises 安装为当前项目可用的 skill”。

## 怎么用

以下示例发送到 Codex 的对话输入框。

**提出知识点：**

```text
使用 $generate-cpp-exercises，给我出一道进程调度练习题。
```

AI 会先给出练习方向供你选择。选定后，可以继续回复：

```text
做进程调度演示器，用时间片轮转。
学生会 C++ 基础，只做模拟，先不要答案。
```

**希望 AI 自己选场景，直接出题：**

```text
使用 $generate-cpp-exercises，针对条件变量出一道 C++ 练习题。
学生已经会创建线程和使用互斥锁，具体场景你来定，直接给题目，不要答案。
```

**在同一段对话中降低难度：**

```text
题目再简单一点，学生还没学过类，但要保留核心知识点。
```

**需要提示：**

```text
只提示一下怎么开始，不要完整代码。
```

**需要参考答案：**

```text
按刚才的题目补充参考答案，包含 C++ 代码、编译方式和验证说明。
```

**需要保存题目：**

```text
把刚才确定的练习题保存到当前目录的 exercise.md，只保存题面，不附答案。
```
